# 账号起号流程设计（新号 → 日常 → 推关 → 爬塔/强化 → 回推关）

- 日期：2026-11-13
- 状态：待评审
- 范围：单账号从零起步到「每日稳定产出」的完整自动化编排
- 事实源：
  - 配置表 `game-probe/index/luban-tables/`（701 表，已全量解析）
  - 录屏分析 `game-probe/research/daily-videos/DAILY-NOTES.md`
  - 真机实测 `game-probe/research/phone-first-plan.md`（附录 A）
  - 现有引擎 `backend/app/automation/engine.py`

## 1. 结论先行

1. **起号不是「把日常跑一遍」，而是「按解锁阶梯逐步放开日常」。** 配置表实证：挑战之塔要第 2 章 24 关、宝箱/游历要 3-30、公会/竞技场要 4-30。新号前 1~2 周根本做不了完整日常，硬跑只会满屏「未找到入口」。
2. **主循环必须是「日常 → 推关 → 提升 → 回推关」的闭环，而不是线性清单。** 因为：
   - 推关吃体力（5 体力/关，上限 60 → 12 关/天），失败要靠战力；
   - 战力提升的材料主要来自爬塔（前 100 层累计 1215 个装备强化石）和日常活跃；
   - 强化石又只能靠「一键强化」转成战力。
3. **「失败两次后不再尝试」建议落成两级计数**：同一关卡连续失败 2 次 → 该关标记 abandoned；本次运行总失败达到 2 次 → 关闭推关阶段。两者都用配置项暴露，默认 2。
4. **战力只做「准入预估」，不做「通关判据」。** 关卡配置里的 `jumpPower`（第 1 章 5756 → 第 10 章 97 万）与游戏内 OCR 到的战力是否同单位尚未实测，因此真正判停必须用战斗结算结果，战力仅用于决定「值不值得进这一关」。
5. **现有引擎有一处必须先修的事实错误**：`TOWER_ENTRY = "星级挑战"`，但日常任务要求的是「挑战之塔」（2-24 解锁，活动页内），「星级挑战」是 6-1 解锁的另一个系统。两者混用会让日常项永远判不过。
6. **日常可零囤货做到 100 活跃**：登录/体力/强化/塔/竞技场/黑市 + 巨龙巢穴/星界树/幻剑空岛/宠物升级，共 10 项 ×10。开宝箱、开蛋、抽装备、藏品升星、充值这 5 项默认不做。
7. **副本失败要转扫荡**：每副本每天 2 次钥匙（咕噜 1 次），打最高层失败后用「扫荡上一难度」把剩余次数用完；巨龙巢穴每次返还 10~45 体力，必须最先做。
8. **游历只换资源、不推进度**：100 体力档 = 20 倍产出。体力 ≥100 时先游历换金币再提升，剩余体力推关；<100 时全部推关。
9. **提升不止强化**：起号期可自动做的是天赋（金币）、装备强化（强化石）、装备进化（图纸，卡天赋 4/9/19/34）、宝石合成、宠物升级；传承/巅峰/坐骑/神器/图鉴属于后期，不做。

### 2.3 爬塔 → 强化闭环

来源：`tbtowerchallenge_tower.json`、`tbtowerchallenge_towerlevel.json`、`tbequip_updatelevel.json`

| 项 | 数值 |
|---|---|
| 塔规模 | 300 座 × 10 层 = 3000 层 |
| 怪物战力 | 第 1 层 7,600 / 第 10 层 12,000 / 第 50 层 56,700 / 第 100 层 281,900 |
| 强化石产出 | 第 1~100 层累计 **1,215** 个（每层 10 个，整十层略多） |
| 强化消耗 | 6 条装备线，各 100 级；每条到 20 级 **525** 石、到 50 级 3,630 石 |
| 六线到 20 级 | **3,150** 石 |

结论：新号把塔打到 100 层左右，刚好够把六件装备强化到 15~20 级。**爬塔是强化石的唯一稳定来源，强化是推关失败后的第一手段**，所以顺序必须是「塔 → 一键强化 → 回推关」。

### 2.4 日常面板的真实结构

来源：`tbtask_dailytask.json`、`tbtask_dailyactive.json`

- 每日任务共 15 项，其中「充值」「藏品升星」配置为不可见（`UnlockNeed = -1`）。
- **零囤货可做 10 项、合计 100 活跃**：登录(10) + 消耗体力30(10) + 装备强化(10) + 塔或地牢(10) + 竞技场(10) + 黑市购买(10) + 巨龙巢穴(10) + 星界树(10) + 幻剑空岛(10) + 宠物升级(10)。
- 需要囤货或付费的 5 项：开宝箱×3、开宠物蛋、抽装备、藏品升星（隐藏）、充值（隐藏）。**默认全不做**。
- 因此「100 档」在副本与宠物解锁后是**可以零囤货拿到的**，之前认为「80/100 必须动囤货」的判断需要修正；早期解锁不全时按实际可用项计算。
- 活跃奖励：20 档银钥匙、**40 档体力 15**、60 档青铜宝箱×3、80 档宝石 50+白银宝箱、100 档高级炼金试剂×2+黄金宝箱。
- 刷新时间 8:00；竞技场开放 00:15–15:59（新服 08:00–23:00）。

### 2.7 副本：挑战失败即扫荡

来源：`tbdungeon_dungeonbase.json`、`tbdungeon_dungeonlevel.json`

| 副本 | 钥匙 | 每日次数 | 主要产出 |
|---|---|---|---|
| 突袭巨龙巢穴 | 81 | 2 | **体力 10~45 + 宝石 10~74 / 次** |
| 突袭星界树 | 82 | 2 | 宠物蛋 + 宠物粮 |
| 突袭幻剑空岛 | 83 | 2 | 掉落表（dropID） |
| 突袭潮汐神殿 | 84 | 2 | 材料 35 |
| 咕噜矿场 | 85 | 1 | 材料 63 |

执行规则：

1. 每个副本先打**当前可挑战的最高层**；通过则继续下一层，直到次数用完。
2. **挑战失败 → 立刻改用「扫荡」把剩余次数扫在已通关的最高层**（界面有 `扫荡` / `扫荡上一难度`）。
3. 若从未通关过任何一层（扫荡不可用），则该副本本次直接跳过，不补钥匙、不看广告。
4. 巨龙巢穴给体力，**必须最先做**，它直接决定当天能推多少关。

### 2.8 游历：批量把体力换成金币

来源：`tbchapter_sweep.json`、语言表 `ui_sweep_*`

| 体力档位 | 等效倍率 |
|---|---|
| 5 | 1x |
| 15 | 3x |
| 25 | 5x |
| 50 | 10x |
| **100** | **20x** |
| 250 | 50x |
| 500 | 100x |
| 1000 | 200x |
| -1（月卡/加速档） | 500x |

- 倍率 = 体力 ÷ 5，等效「打同等体力数量的关卡产出」，**不推进新关卡**，只产资源。
- 解锁：UI 文案为「通关第一章解锁游历」，功能表 `function 23` 写的是 3-30，两者冲突，按真机实测为准。
- 中断后续跑不重复扣体力（`sweep_continue`）。
- **触发规则**：先推 6 关完成「消耗体力 30」→ 若剩余体力 ≥ 100，做一次 100 体力游历 → 用金币/材料提升 → 剩余体力继续推关；剩余 < 100 则不做游历，全部用于推关。
- 理由：起号期卡点是战力而不是章节数；100 体力游历能在不增加操作量的前提下把体力换成金币，喂给天赋/强化。

### 2.9 养成系统全景与起号取舍

| 系统 | 消耗 | 门槛 | 起号策略 |
|---|---|---|---|
| 天赋等级 | 金币 200/级；每 10 级 20 宝石突破 | 1-1 | 每天升到金币不足；整十突破需授权 |
| 装备强化 | 装备强化石 | 1-1 | 一键强化，最高优先级 |
| 装备进化（进阶） | 装备图纸 | 天赋 4 / 9 / 19 / 34 | 达到门槛即做 |
| 装备合成 | 2~3 件同名同品质 | — | 背包满时做 |
| 宝石合成/镶嵌 | 5 颗同级 → 1 颗高级 | — | 每天做 |
| 宠物升级 | 宠物粮 | 2-60 | 做（同时完成日常项） |
| 宠物培育/词条 | 材料 | 10-5 | 后期 |
| 传承 | 研究时间/加速 | 天赋 74 | 后期 |
| 巅峰天赋 | 专精点 + 冒险之书 | 后期 | 不做 |
| 坐骑/神器觉醒 | 材料 | 后期 | 不做 |
| 图鉴升星 | 天外陨铁 | 后期 | 不做 |
| 冒险者升星 | 碎片 | 后期 | 不做 |

起号期性价比排序：**天赋（金币）→ 装备强化（石）→ 装备进化（图纸）→ 宝石 → 宠物 → 其他**。
其中「天赋整十突破」要花 20 宝石（`tbherolevelup.gradeUpCost`），但不突破就卡在 9/19 级，装备进化也无法进入下一档。建议做成配置项 `allowGemTalentBreakthrough`，默认关闭，开启后最多突破到 19 级。

## 3. 流程总览

```
S0 构建新账号
   └─ 登录/选区/建角/新手引导/首日弹窗清理
        ↓
S1 基线采集（战力、章节关卡、体力、钻石、强化石、已解锁功能）
        ↓
S2 日常（按解锁过滤，先做不耗体力的项，副本失败即扫荡）
        ↓
S3 推关（消耗体力；逐关记录成功/失败）
        ↓
S4 提升（游历换金币 → 天赋/强化/进化/宝石 → 挑战之塔 → 战力复核）
        ↓
S5 回推关（同一关最多再试 1 次；再失败即放弃）
        ↓
S6 收尾（回主城、落盘 state、出日报）
```

**2026-11-14 主线收紧（优先于本文早期的全日常设想）**：`bootstrap` 执行「基线 → 日常 → 公会 → 船 → 活动副本 → 挑战之塔 → 游历 → 推关 → 天赋/装备提升 → 回推」。竞技场、黑市、区服遍历不进入该任务；未知玩法不校准、不尝试。

**2026-11-14 优先级调整**：用户要求「优先完成每日任务，然后是公会、船，再是推关任务」。`all` 与 `bootstrap` 均按 日常 → 公会 → 船 → 推关 的顺序执行；每项完成后写入账号集合的完成记录。原「主线不做日常/公会」的收口口径自此失效。

要点：

- **S2 与 S3 共享体力**。日常里的「消耗体力 30」不单独做，直接由 S3 的推关满足，避免先花 6 关体力再重复。
- **S4 是条件触发**：只有 S3 出现失败、或材料足够、或塔有可打层数时才进入；否则直接收尾。
- **S5 只回试「被卡的那一关」**，不重新跑整章。
- 整个流程以「单账号一次运行」为单位，结束后可被第二天的定时任务重新拉起。

## 4. 分阶段设计

### S0 构建新账号

两种模式，自动化只负责其中可控部分：

| 模式 | 前置 | 自动化范围 |
|---|---|---|
| A. 已有账号开新服角色（主用） | 账号已登录 | 选区→建角→引导→首日清理，全自动 |
| B. 全新账号注册 | 手机号/短信验证 | **人工完成注册与首次登录**，之后交给 A |

建角步骤：

1. 确认设备处于登录页或选区页（OCR 命中「最近登录」「服务器」「开始游戏」）。
2. 进「服务器」tab，选目标区服（按区服名匹配，不按序号，防止排序变化）。
3. 创建角色：有随机名则用随机名；要求输入则用 `前缀+序号`（如 `capy001`），输入后确认。
4. 进入强制新手引导，按 `tbguide_guide.json` 的组顺序跟随：
   `3 天赋 → 4 商城免费 → 5 装备穿戴/强化 → 6 副本与塔 → 7 宠物 → 8 扫荡 → 15 宠物捕捉`
   实现策略：**只点屏幕高亮/引导遮罩内的目标**，不点遮罩外的坐标；每组以「目标控件名对应的页面特征」判定完成。
5. 首日弹窗清理：公告、更新确认、里程反馈、限时礼包、广告。统一「只点关闭/确认，不点购买」。
6. 领取首日免费资源：邮件、签到、7 日任务、新手免费档（`BtnBuyFree`）。

退出条件：连续 3 次识别不到引导遮罩，且主城锚点（`btn_menu` + 底部导航）稳定命中 → 认为引导完成。

### S3 推关

推关有两种模式，按账号数量选择：

- `full` 全量：每一屏都做 OCR 识别，最稳但单局约 7–13 秒/帧，适合首次校准或界面变动后。
- `lean` 精简：把最近一次成功推关的点击坐标与间隔录成脚本（`backend/.data/stage_script.json`），之后按定时点击回放；每 N 次点击（默认 8）做一次界面校验，出现结算就点返回并确认回城，出现真实失败则记失败，界面偏离局内就自动回落为逐帧识别。适合账号很多、需要缩短单局耗时的场景。

两种模式都会录制点击位置，只有 `lean` 会回放；回放只发生在刚点「开始」进入新一局时，续跑中的局和爬塔不走回放。每完成一项工作（日常/公会/船/推关）会把账号名与完成时间写入账号集合（`backend/.data/accounts.json`），可通过 `GET /api/accounts` 或设备面板查看。

入口与内循环复用现有实现（`_stage` / `_play_run`），新增门控与计数：

```
while 未停止:
    if stamina < 5: 退出推关
    if 总失败次数 >= maxStageFails: 退出推关
    if 当前关卡 in abandoned: 退出推关
    进入当前关卡
    result = 打一局()
    if result == 成功: 记录通关，继续
    else:
        记录失败(关卡号, 原因)
        if 该关失败次数 >= 2: abandoned.add(关卡号)
        退出推关 → 进入 S4
```

**失败判定（四个来源，任一即算）**

1. 结算页 OCR 命中「失败」。
2. 单局超过 `max_run_seconds`（默认 600s）仍无结算。
3. 连续 6 轮无任何可点击动作（现有 `_play_run` 的 idle 判据）。
4. 连续 3 次点「开始」仍未进入关卡。

**不要用「战力 < jumpPower」直接判失败**，只作为进入前的警告日志。

**推关加速手段（按收益排序）**

| 手段 | 效果 | 实现方式 |
|---|---|---|
| 内置「战斗 2 倍速」 | 2x，免费 | 2-60 解锁（`function 100`），开局即开 |
| 外部变速器 | 5~8x | 冲鸭悬浮窗只开变速，关闭连点/录制 |
| 跳过动画/对话 | 省 1~3s/次 | 命中「跳过动画」「点击跳过」优先点 |
| 技能默认第一张 | 省 0.5~1s/次 | 快速模式已实现，不做优先级遍历 |
| 单按钮多态合并 | 减少识别次数 | 底部 (600,2460) 一个坐标覆盖 下一天/战斗/拾取/打开 |
| OCR 降频 + ROI | 省 100~300ms/帧 | 战斗中 1.2s 一帧；只在底部条与技能区做局部识别 |
| 结算原地续战 | 省回城往返 | 结算页优先「再次挑战/下一关」，不回主城 |
| 塔「自动下一层」 | 免逐层点 | 打开开关后只点 1 次挑战 |
| 游历批量 | 不推进关卡，但把刷资源从逐关战斗里剥离 | 见 2.8 |

基准：外部 5x + 内置 2x 下，一局 7 天约 40s；12~15 关约 8~12 分钟。**月卡 4 倍速属于付费项，不做。**

### S4 提升

按性价比固定顺序执行，每步都有「无收益即退出」判据：

1. **游历换金币**（体力 ≥ 100 时）
   - 仅在「消耗体力 30」已完成、且剩余体力 ≥ 100 时执行；
   - 选 100 体力档（20x），等「游历结束」；
   - 中断则点「继续游历」（不重复扣体力）；
   - 剩余体力 < 100 时**跳过本步**，留给 S5 推关。
2. **天赋升级**（金币）
   - 金币足够就逐级点，直到金币不足；
   - 整十级突破需 20 宝石：`allowGemTalentBreakthrough=false` 时停在 9/19/29…；
   - 开启时最多突破到 19 级（解锁装备进化第 3 档即止）。
3. **装备进化/进阶**（图纸）
   - 先读天赋等级，达到 4/9/19/34 门槛才进；
   - 只进化当前穿戴的 6 件，不做合成赌博。
4. **宝石合成/镶嵌**
   - 5 颗同级合成 1 颗高级；优先攻击/生命词条；
   - 不重置、不洗练（洗练是后期项）。
5. **宠物升级**（宠物粮）
   - 升 1 级即可，顺带完成日常项；宠物粮不足即退出。
6. **挑战之塔**（活动 → 挑战之塔）
   - 打开「自动下一层」，点 1 次挑战；
   - 打到 `towerFloors` 层，或连续 2 层失败即停；
   - 只点「挑战」，不点「扫荡」「购买次数」。
7. **一键强化**（背包 → 装备 → 一键强化）
   - 把上一步刚拿到的强化石立刻消耗掉；
   - 只花强化石，不花钻石；强化石不足或按钮置灰即退出；
   - 记录强化前后战力。
8. **战力复核**
   - 若战力提升 ≥ 5%，回 S5；否则直接收尾，避免「提升无效 → 反复推关」空转。

> 顺序依据：先花金币/材料（不依赖战斗），再打塔补强化石，最后统一强化；这样「塔产出的强化石」能在同一次运行里立刻转成战力，而不是留到第二天。

### S5 回推关

- 只重试 S3 标记的那一关，不重跑整章。
- 成功 → 恢复 S3 正常循环（继续吃体力）。
- 第 2 次失败 → 该关 abandoned，**本次运行不再推关**，进入 S6。
- 若体力已不足 5，直接 S6。

### S6 收尾

- 连续返回直到主城锚点命中（最多 6 次，沿用 `_back_to_adventure` 的退避策略）。
- 落盘 `state.json`：账号/区服/章节/关卡/战力/体力/强化石/今日各任务完成度/失败记录/abandoned 列表。
- 生成一句话日报，写进现有 automation 日志队列。

## 8. 验收标准

- 建号：连续 3 天新开 3 个区服角色，全部能自动过引导进主城，无一次误点付费。
- 日常：解锁项完成率 ≥ 90%，未解锁项必须记 `skipped` 而不是 `failed`；解锁齐全时应能拿满 100 活跃。
- 副本：挑战失败后必须转为扫荡，剩余钥匙不浪费；扫荡不可用时记 `skipped` 并说明原因。
- 游历：体力 < 100 时绝不触发；触发后必须等「游历结束」或记录中断原因。
- 推关：同一关失败 2 次后不再发起第 3 次点击；日志能给出失败原因与截图。
- 提升：每次运行至少完成「天赋/强化/进化/宠物」中的一项，或明确记录「材料不足」。
- 资源红线：钻石消耗 = 0（除非显式开启天赋突破），广告触达 = 0，囤货箱/蛋/钥匙消耗 = 0。
- 断点：中途停止后再次启动，能从记录关卡继续，不重跑已通关章节。
